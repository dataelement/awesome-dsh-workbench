# 工作台投稿材料模板

这是人工审核的文档模板，不是可安装工作台、已收录条目或正式机器 schema。请填写实际信息，删除说明文字；未验证项注明“未验证”。

产品规范是 [DSH Desktop 工作台开发指南](https://dshdesktop.com/workbench/skills/workbench-development/SKILL.md)。本模板与之对齐，行为描述以规范第 1–4 节为准。

## 基本信息

| 内容 | 填写值 |
| --- | --- |
| 工作台名称 / 标识 | 待填写 |
| 本次版本 | 待填写 |
| 作者 GitHub 用户或团队 | 待填写；不填写个人邮箱 |
| 作者源码仓库 | 待填写 |
| 完整 commit SHA | 待填写；不只填分支或 tag |
| 安装包地址与 SHA-256 | 如提供安装包则填写 |
| 已验证的 DSH Desktop 版本 | 待填写 |
| 源码及资源授权说明 | 待填写 |

## 材料格式与大小

- **工作台包**（`.tgz`）：gzip tar 格式，不超过 **8 MB**；附 SHA-256，且能追溯到基本信息中填写的 commit。
- **产品截图**（可选）：**PNG / JPEG / WebP**，单张不超过 **2 MB**，总共 1–5 张；只展示产品界面，不含真实凭据或业务数据。
- **路径**：材料文件保存为 `submissions/<工作台标识>/<版本>.md`（如 `submissions/dsh-site-selection/1.2.0.md`），便于审核者按版本归档。

## 解决什么工作

说明目标用户、典型任务、使用入口及预期成果；附界面截图或演示链接。

## 安装与使用

填写安装、初始化、会话创建与恢复、移除的可复现步骤。说明默认 preset、工作区选择、宿主依赖和缺失接口；不得把尚未实现的接口描述为正式 SDK。

## 权限与依赖

列出外部服务、工具、网络及文件访问需求、凭据配置方式、费用和限制。不要填写真实凭据或私人数据。

## 本次版本与验证

说明变更内容、兼容范围及升级影响。逐条对照规范第 1–4 节写出实测步骤、结果、环境和证据，特别覆盖原生会话、单前台切换、后台任务及用户状态保留。

## 已知问题

列出未验证场景、依赖宿主的待实现能力和其他限制。
