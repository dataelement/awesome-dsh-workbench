# 工作台目录审核清单

## 自动检查

- [ ] 投稿只修改一个 `data/workbenches/owner__repo.yml` 和脚本生成的 `dist/catalog.json`。
- [ ] YAML 通过严格 schema 校验，没有多余字段。
- [ ] 文件名和 `url` 指向同一个 GitHub owner/repo。
- [ ] 分类存在，生成的 `dist/catalog.json` 没有差异。
- [ ] 如填写 Release，地址属于同一仓库、文件为 `.tgz`，并填写 SHA-256。

## 人工检查

- [ ] 仓库公开可读，作者身份和许可证清楚。
- [ ] 名称与中文介绍准确，不夸大能力，不包含联系方式或广告信息。
- [ ] README 说明安装、使用、权限、外部服务、费用和已知限制。
- [ ] 工作台已按 DSH Desktop 开发指南在本机安装并实际打开验证。
- [ ] 没有密钥、个人数据、构建产物或二进制包混入 PR。
- [ ] Release 包（如有）能追溯到仓库代码，校验值与下载文件一致。

合并表示目录收录。工作台的安全、修复和后续版本仍由作者负责；发现恶意行为、失效来源或严重风险时，维护者可以下架条目。
