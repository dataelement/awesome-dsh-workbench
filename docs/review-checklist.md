# 验收清单（准备稿）

审核者按此清单核对每一份投稿。提交者也可对照此清单自查。

权威的产品规范是 [DSH Desktop 工作台开发指南](https://dshdesktop.com/workbench/skills/workbench-development/SKILL.md)，本清单与之对齐，规范不移动。

## 前置条件

- [ ] **本机实际安装**：工作台已在本机装好且用户实际打开使用过。
- [ ] **材料完整**：[投稿指南](../CONTRIBUTING.md) 列出的勾选清单全部覆盖。

## 行为核对（按规范章节）

- [ ] **§1 定义与界面边界**：公共入口不被遮挡；`customFrame` 根布局、绝对定位、最大化与拖拽都在宿主区域内。
- [ ] **§2 工作台、会话与工作区**：一个工作台可关联多个会话，每个会话最多归属一个工作台；工作台与工作区是多对多。
- [ ] **§3 未绑定会话时的使用**：无会话也立即显示业务面板；原生会话区可直接创建工作区和会话；已有会话恢复原有映射而非被覆盖。
- [ ] **§4 固定入口与切换**：同时只有一个前台工作台；切换不停止后台任务；绑定会话精确唤起其 owner；卸载的工作台不自动重装。

## 验收记录

审核者在 PR 中记录：本次工作台版本、源码 commit 或固定包提交标识、包校验值、宿主版本、验证结果和未解决问题。结论使用「通过 / 待补充 / 未通过」，并写明理由。修改源码或发布新版本后重新验收。

目录收录只对已验收版本有效；最终在线发布方式及审核自动化仍待实现。
